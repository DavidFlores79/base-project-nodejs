# Analyze Bug Workflow

This workflow helps you investigate bugs and Sentry issues systematically.

## Steps

1. **Receive Bug Information**
   - Get the Sentry issue ID or bug description from user
   - Example: `<sentry_issue>ISSUE_ID_HERE</sentry_issue>`

2. **Investigate the Issue**
   - Review error stack traces and context
   - Check affected files and code paths
   - Identify potential root causes
   - Review recent changes that might have introduced the bug

3. **Analysis Only**
   - DO NOT perform any fixes or modifications
   - Only provide investigation findings and recommendations
   - Explain the likely cause and suggest potential solutions

4. **Report Findings**
   - Summarize the root cause
   - List affected components
   - Provide recommendations for fixes
